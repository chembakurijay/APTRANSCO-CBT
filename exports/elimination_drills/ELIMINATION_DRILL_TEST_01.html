Q1 — Answer

Keyed answer: D — \(3/7\), rises to \(3/5\)

Governing elimination rule: Playbook Rule 1 — Diameter ↔ radius / area geometry slip

Why this option (under Rule 1):

It is the only choice consistent with the rule’s check: Compute A = πd²/4 (or r = d/2) once on scratch paper. Eliminate options that match P/(πd²), P/(πr), or treating d as r.

Why not the other options (elimination):

  • A) \(1/2\), unchanged — Eliminate: Geometry / area path does not match πd²/4 from the stated diameter (radius↔diameter slip).
  • B) \(4/7\), falls to \(2/5\) — Eliminate: Geometry / area path does not match πd²/4 from the stated diameter (radius↔diameter slip).
  • C) \(3/5\), rises to \(6/7\) — Eliminate: Geometry / area path does not match πd²/4 from the stated diameter (radius↔diameter slip).

Takeaway: When you see this pattern again, apply Rule 1 before full algebra — strike lookalikes that violate the rule, then confirm the survivor.

Governing elimination rule: Playbook Rule 5 — Per-unit base-change scaling

Why this option (under Rule 5):

It is the only choice consistent with the rule’s check: Zpu ∝ Sbase / Vbase². If Sbase doubles and Vbase fixed → Zpu halves. Eliminate ‘unchanged’, ‘doubles’, or ‘squared’ unless the stem changed Vbase too.

Why not the other options (elimination):

  • A) A false R true — Eliminate: Wrong pu scaling when base MVA/kV changes (Zpu ∝ Sbase/Vbase²).
